# Test audio

Put a short Hindi or English speech sample here (e.g. `sample.wav`) to test
Stage 1 (`scripts/test_stt.py`) in isolation, before wiring up the full app.

No sample is bundled — record one yourself:
- Windows: open **Voice Recorder** (Start menu), record a sentence, export/find
  it in `%USERPROFILE%\Documents\Sound recordings\*.m4a`.
- Or record straight from the running frontend once Stage 6 is wired up.

Any format ffmpeg/PyAV can read works: `.wav`, `.mp3`, `.m4a`, `.webm`.
